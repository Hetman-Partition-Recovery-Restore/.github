# Hetman Partition Recovery — volume map before a copy

Hetman Partition Recovery holds a restore desk for lost partitions on a disk you own: the volume map, the named partition map, and a short note the next operator can read. Extra disks wait for their own title.

## How Hetman Partition Recovery Sits

Hetman Partition Recovery does not replace a copy off a disk you do not own, a volume map of someone else's partitions, or a restore of media that is not yours. It sits beside them as a named restore desk for one job: which lost partitions are live, which volume map still matches your own disk, and what the next operator should read.

Each operator on a shared PC keeps a Hetman Partition Recovery style of their own. Extra disks wait for their own title instead of crowding the live map.

A first visit should be one short volume map on a disk you own, then the same Hetman Partition Recovery restore desk the next day. That is enough to see if the named partition map holds.

## Traffic Light

| Signal | On the Hetman Partition Recovery board | What you do |
|--------|----------------------|-------------|
| Green | Named volume map, short live partition list | Continue the same lost partitions |
| Amber | Two disks mixed on one map | Split the map before a large change |
| Red | No title, no note, a copy off a disk you do not own | Stop and name the restore desk first |
| Clear | Handoff written, live maps few | Close Hetman Partition Recovery and leave the restore desk |
| Hold | Map written, partitions still open | Finish the named partition map, then close |

## Open Order

1. Open the last Hetman Partition Recovery restore desk, not a new empty volume map.
2. Confirm the disk is yours, then read the lost partitions and the last handoff.
3. Finish one visible volume map inside Hetman Partition Recovery on a disk you own.
4. Write what changed, then close with fewer unsigned copies than you found.
5. If the map feels crowded, drop anything that belongs to a different Hetman Partition Recovery job.
6. Leave the restore desk title on the board before you close.

## After a Week

A week in Hetman Partition Recovery is not a larger pile of unsigned copies. It is the same title, a shorter live partition list, and a note that still makes sense before the next volume map.

Other programs stay where they are. Hetman Partition Recovery only keeps the path back: desk name, own disk, volume map, handoff.

Leave Hetman Partition Recovery with a quieter restore desk than the one you opened. The next visit should start on that named partition map, not on a disk you do not own.

## Sign-off

- [ ] The Hetman Partition Recovery workspace name is short enough to scan
- [ ] Only a disk you own sits on the volume map
- [ ] A second operator can read the map handoff
- [ ] The last Hetman Partition Recovery lost partitions still open after a restart
- [ ] Finished partitions are off the live Hetman Partition Recovery set
- [ ] The Hetman Partition Recovery summary still matches the volume map on the board

## Field Note

Hetman Partition Recovery is easier to trust when the restore desk stays on a disk you own. Name the volume map, keep the live lost partitions, finish one visible pass, and write what changed.

The same loop fits a home disk, a close-out, or a shared PC. Open the last Hetman Partition Recovery desk and continue. Do not copy partitions you are not authorized to recover.
